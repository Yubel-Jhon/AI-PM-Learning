# chat-persona · 人物分析（趣味向）

## 傻瓜流程（用户只需要说"分析一下张总"）

1. 你自己跑 `python persona_export.py --list` 对人名（有重名/找不到再问用户，平时别问）
2. 默认参数跑 export 出语料；语料太少就顺口问一句"有微信导出吗？或者贴几句他的原话也行"；
   一句原话都没有（刚加上好友）→ 直接走下面的「初见陌生人：头像识人」
3. 出**趣味人物卡**（结构见下），屏幕上只放 称号+标签墙+MBTI梗+攻略难度+3do/3don't
4. 收尾**必问一句**："MBTI 猜得准吗？不准你直接钦点一个（比如'张总是INTJ'），以后都按这个来。"
5. 用户报了型 → `python persona_export.py 张总 --set-mbti INTJ` 记下来；之后所有卡
   MBTI 行标「用户钦定」，四轴证据只用来写"为什么像"，不再自行翻案。
6. 卡被认可后主动提一句："要把分寸落到嘴替吗？落了以后改写自动带着这套分寸。"
   （落缓存两件套见下节——这是把"改写"和"人物分析"两个功能焊起来的那颗螺丝。）

## 分工

- 机械部分**必须**用 `persona_export.py`（本目录下），不要手翻数据库：
  该人出现的所有窗口（单聊+群聊）自动拉出，按时间窗分层，算客观信号，
  产出 `<库目录>/persona_cards/<人名>/{corpus_recent.md, corpus_old.md, stats.json}`。
  常用：`--list` 看库里都有谁；`--months 1` 收窄窗口；`--extra 文件` 合并外部语料；
  `--db` 换库；`--set-mbti 型` 钦点。
- 分析、称号、梗、分寸由你出。头像库里没有——让用户把对方头像图片直接贴进来（或截图），
  你看图归类；网名不用问，conv_name（备注名）和群昵称（sender）就是。

## 语料分层（判断只基于窗口内）

- **窗口内（近 N 月，默认 3）＝细读层**：逐条读。
- **窗口外＝概括层**：压成 ≤5 条精炼概括（关系怎么开始、早期基调、重大事件），
  只放"历史轨迹"栏做背景，**不**参与信号和性格判断。
- **多源语料**：`--extra` 支持 .json / .csv（微信导出留痕/MemoTrace 列名能认）/
  .txt（`张三：消息` 或裸文本）。发送者名对不上会告警，先确认是同一人。
- **冷启动**：库里没这个人也行——**第一步先头像识人**（零语料就有初版分寸，见下节）；
  用户贴原话（≥5 句）存 .txt 走 --extra，或口头描述，再升级出**假设人物卡**：
  卡头标 `⚠ 假设人格（样本来源：用户提供，未经库内核实）`，
  MBTI 置信度封顶"弱"，分寸给保守版，头像信号降权成参考（衰减曲线见下节）。
- **已有旧卡**：重分析前先读旧卡的「近期观察」段——那是 zuiti-rewrite 改写端回写的实况
  （新招式 / 判断被打脸 / 用户改稿方向），比任何概括都新鲜；消化进新卡（证实留用、打脸修正），
  别让回路断在分析端。
- **样本量**：person_recent_msgs < 30 → 只出统计卡+标签墙，MBTI 明说"样本不够纯看猜"；
  30~100 → 置信度封顶"中"；≥100 正常。

## 方法论：三把尺子 + 一把翻译（出卡的每句话都要能倒推回数据）

分析不是拍脑袋，顺序固定：**先解构说话 → 再判型 → 再定代际 → 最后翻译成应对策略**。

### 尺子① 说话解构（stats.json 客观数据，五维）

| 维度 | 信号 | 读法 |
|---|---|---|
| 节奏 | 主动率 initiation_rate、回复延迟 reply_median_min | 谁迁就谁：总是 TA 先开口=关系里的发动机；≤15min 秒回 vs ≥4h 靠缘分 |
| 体量 | 平均句长 avg_len | ≤15 惜字如金；≥40 小作文选手 |
| 情绪 | emoji_rate、语气词 particles、问句率 question_rate | 表情包战士 / 问号控 / 语气生硬 |
| 生物钟 | 时段 hour_hist | 20-24/0-4 占比>40% = 夜行型 |
| 代际 | era 年代锚点 | 见尺子③ |

规则：**只引用 stats.json 里真实存在的数字**，数据没有的不编；样本<30 只出统计卡。

**去向（2026-09 升级）**：五维拼进 MBTI 四维——主动率→E/I · 句长与梗→S/N ·
emoji 语气→T/F · 时间死板→J/P。每一维都有数撑着，四条一起数 → 型，落进人物卡
（拼装口径见尺子②）。核心原则：**数字全是数出来的，模型只负责解读——MBTI 不是玄学，
是同一批数字拼出来的。**

### 尺子② MBTI 四轴（每轴 = 倾向 + 置信度 强/中/弱 + 原句依据）

- **E/I**：主动发起率、群里发言密度、短句高频轰炸(E) vs 少而长(I)
- **S/N**：时间地点数量、纠细节(S) vs 比喻、"感觉"、聊趋势(N)
- **T/F**：就事论事、甩数据、因果连接词(T) vs 关心人的状态、"辛苦/别急"、情感词多(F)
- **J/P**：时间点说死、"定下来/排期/清单"(J) vs "到时候看/可能/也许"、省略号感叹号多(P)

**拼装口径（2026-09 升级，五维数据 → 四维判型，不用对方做测试也不用猜）**：

| 轴 | 吃哪个数据 | 拼法示例 |
|---|---|---|
| E/I | 主动率、发言密度 | 两轮对话都是他先开口（主动率 100%）→ E |
| S/N | 句长、梗密度、话题 | 句长 16 字 · 0 梗 · 只说事不说感觉 → S |
| T/F | emoji 率、语气词、用词 | 0 emoji 0 语气词 · 张口就是数字和时间 → T |
| J/P | 时间词死活、计划词 | 时间说死 · 22:13 还在批方案 → J |

张总实测：四条一起数 → **ENTJ**。同样这四条，喂给改写引擎就是「强硬 · 火气」那档
（判型→档位联动，见 zuiti-rewrite 联动节）。

学术边界（决定置信度话术）：语料库研究里 **T/F 维度可预测性最高、J/P 最低**，
且效果量普遍不大、个体差异大于类型差异——所以置信度最高给到"中"，写依据时引原句。
MBTI 本身是参考级标签（红线已有），不写成心理诊断。

### 尺子③ 年龄推断（语言地层学 + 头像网名信号）

stats.json 的 `era` 字段直出命中：**era_hints**（四层聚合：70-80后/85-95/90-00/00-05后）、
**markers**（具体词+次数）、**bracket_emoji**（微信 [微笑][玫瑰]一族 = 独立的中老年信号）。

**头像网名信号（2026-09 升级，权重高于词表）——头像和网名比聊天记录更诚实：
不背词表，词会过时，频率和形象不会骗人；网名头像能换，说话习惯改不掉。** 三原型对照：

| 原型 | 网名 | 头像 | 说话 | 落位 |
|---|---|---|---|---|
| 网名是心境 · 头像是风景 | 清风明月 · 海阔天空 · 平安是福 | 山水 · 荷花 · 日出 · 全家福 | 零梗零 emoji · 爱用 [微笑][玫瑰] · 爱转发养生文 | 往年长排 |
| 网名是身份 · 头像图省事 | 张总 · 厦门-建材-王姐 · Leo·采购 | 默认字母图 · 汽车 · 背影照 | 0 emoji 0 梗 · 句句带数字和时间 | 中间地带 |
| 网名是梗 · 头像是二次元 | 那咋了 · 尊嘟假嘟 · Ivy☆ | 动漫 · 游戏截图 · 情头 | 梗密集 · 表情包战士 · 大小写混符号 | 往年轻排 |

- **网名定调**：心境型（山水/平安/知足）往年长；身份型（真名/职位/地区-行业-姓名）中间；
  玩梗型（热梗/符号/花体英文）往年轻
- **头像定档**：风景·祝福字·书法·插花·全家福＝正式少梗岁月静好系 → 年长；
  默认字母图·汽车·背影照·商务壁纸·娃照·球星＝身份和生活都在头像里 → 中间；
  动漫·游戏截图·情头·韩风手绘·插画＝好看和好玩优先 → 年轻
- **词表与头像网名打架 → 以头像网名为准、词表做旁证**（词表是旧的，头像网名是现在的）

原理：语言习惯在青春期定型，强锚点词使用峰只有 1~2 年、世代辨识度极高。判读规则：

1. **词汇组合定段**：单词 ±5 岁，两个以上同层锚点才敢报该层（组合可到 ±3 岁）
2. **形成期锚定**：中年人用"呵呵"多半是当年的真诚笑义，不是嘲讽；"70-80后"词层出现
   只说明早期网民，不等于本人年纪
3. **跨层混杂**：以最高频层为主，卡上如实写"代际信号混杂"
4. 没有锚点就写"语言层无代际信号"，**不硬猜**；输出=年龄段+置信度+依据词（有头像网名
   信号时引网名/头像内容，如：默认字母头像 · 名字就是「张总」→ 中间地带）
5. 与 MBTI 同级娱乐参考，不下结论

### 翻译表：从人物卡到嘴替改写（怎么应对他说话）

人物分析的价值在改写端兑现——四轴 + 代际 → 说话策略：

| 判断 | 改写策略 |
|---|---|
| I（内敛） | 别连环轰炸，给思考时间 |
| E（外放） | 短句即时来回，节奏放开 |
| S（具体） | 给时间/地点/数量，少谈概念 |
| N（抽象） | 先给方向和为什么，细节放后 |
| T（讲理） | 先结论后理由，直接上数据 |
| F（重情） | 先接住情绪再谈事 |
| J（计划） | 时间说死、给明确下一步 |
| P（灵活） | 留弹性、别逼死线 |
| 长辈代际 | 少用网络梗，称呼工整、句读干净 |
| 同辈/年轻 | 可以带梗，句式放松 |

落法：人物卡 3do/3don't 从这张表**挑最对症的三条**（禁止空写"多沟通"）；
回灌关系卡后改写端自动吃到——卡的分寸盖过 zuiti-rewrite 通用分寸表（先人格，后招式）。

## 初见陌生人：头像识人（2026-09 新增，零语料冷启动）

刚加上好友，一句聊天记录都没有——**头像就是第一句话**。触发：用户说"刚加上 XX 怎么聊"，
或分析对象库里查无此人且用户也给不出原话。

**做法**：让用户把头像贴进来（图片/截图都行），网名顺口带一句（或从 conv_name 读），
按尺子②的三原型归类（往年长排 / 中间地带 / 往年轻排），产出**初见卡**：

- 卡头标 `⚠ 初见卡（零语料 · 按头像网名推断，聊几天就作废重排）`
- 只给三样：代际落位 + **初版分寸** + 破冰提醒
- **初见分寸默认**：客气三分，和蔼一点；头像老成、符合刻板印象 → 再严肃一点
  （称呼工整、少梗）；头像年轻、玩梗系 → 再轻松一点（可以带梗，句式放松）
- MBTI **不出**——四维要靠说话数据，头像给不了；卡上明说"聊三五句再回来分析"
- 攻略难度不评——没打过交道，没有"难度"可言

**初印象会过期（衰减曲线，认识越久说话越说了算）**：

| 阶段 | 头像网名权重 | 依据 |
|---|---|---|
| 刚加上 | ≈95%，头像网名说了算 | 只有这俩可看 |
| 聊了三五天 | ≈45%，各占一半 | 说话样本开始积累 |
| 一周往后 | ≈8%，只按说话来 | 语料足够，走正常流程重出卡 |

升级路径：攒到 ≥5 句原话 → 转正常冷启动流程（--extra 出假设卡），头像信号降权成参考；
后续正常分析把初见卡当「近期观察」的前史读，打脸了就修正（"头像看着年轻，实际说话老派"）。

## 趣味层（让卡片好玩，这是卖点不是点缀）

**称号**（从 stats.json 信号挑最扎眼的一两条合成，格式"场景+人设"，例：
"深夜批奏折的甲方"）：
- initiation_rate ≥ 0.7 → 总是他先开口；≤ 0.2 → 全靠你先开口（"养成系朋友"）
- reply_median_min ≥ 240 → 回复靠缘分型；≤ 15 → 秒回型选手
- 时段 20-24/0-4 占比 > 40% → 夜行型；avg_len ≤ 15 → 惜字如金；≥ 40 → 小作文选手
- emoji_rate ≥ 0.3 → 表情包战士；≤ 0.05 → 表情包绝缘体；question_rate ≥ 0.4 → 问号控

**标签墙**：3~5 个 `#xxx`，从上面信号里挑，别编数据里没有的。

**攻略难度**：★☆ 星级 + 半句理由（沟通风格火气/边界越多星越多）。

**MBTI 梗**（16 型一句话，判型后从表里取，可微调别硬搬）：

| 型 | 梗 | 型 | 梗 |
|---|---|---|---|
| INTJ | 脑内方案已改完八版，嘴上一句没说 | ISTP | 话少手稳，出事时全场只有他知道怎么办 |
| INTP | 不是不想回你，是在想"回你"的意义 | ISFP | 佛系上线审美在线，别催，催就是再见 |
| ENTJ | 深夜批奏折白天画饼，饼还是真会兑现的 | ESTP | 先干再想，干完发现也不用想了 |
| ENTP | 你说东他聊西，聊完你发现西也有道理 | ESFP | 团建灵魂笑声制造机，KPI 唯一克星 |
| INFJ | 朋友圈三天可见，你一看穿他他就慌了 | ISTJ | Excel 战神，deadline 是信仰 |
| INFP | 表面"都行"，内心小作文已经一万字 | ISFJ | 默默把活干了，功劳簿上查无此人 |
| ENFJ | 天生氛围组长，你的情绪他先接住 | ESTJ | "开会解决"，解决不完就再开一个 |
| ENFP | 快乐小狗，负责点火不负责收尾 | ESFJ | 最先发"收到"，也最先发现你没吃饭 |

四轴判型的依据和拼装口径见尺子②（五维数据 → 四维判型那张表），此处不重复——
趣味层只管把判好的型变好玩，不另立一套判法（2026-09-21 去重：两处写两遍会改一漏一）。

## 落缓存：和嘴替改写结合（核心闭环）

两个功能是一体的：**改写（修饰当前对话）吃人物分析（身份）的缓存**。改写端每次读三层，
只有第一层是现读的：

| 层 | 内容 | 改写时怎么用 |
|---|---|---|
| ① 近 1 月原文 | context.py 现读 25 条 | "现在聊到哪了"，结合上下文 |
| ② 1~3 月概括 | summaries 表缓存 | "他这三个月什么脾气"，不必重读原文 |
| ③ 1 年以上底色 | summaries 表缓存（更精简） | "这人本质什么样" |

分析完成后**主动提议落缓存**（用户点头就做，两件套）：
1. 人物卡压成 ≤10 行浓缩版存 md（称号+MBTI+分寸 do/don't+称呼句长 emoji 习惯）：
   `python persona_export.py 人名 --card-file 浓缩版.md --db <库路径>`
   → 进 relationship_cards（永久层，改写每次都带）
2. 分层概括存 json（`[{"start":"2025-12-20","end":"2026-06-20","text":"这三个月他……"}`、
   `{"start":"2023-01-01","end":"2025-12-19","text":"更早的底色……"}]`）：
   `python persona_export.py 人名 --summaries-file 概括.json --db <库路径>`
   → 进 summaries 表，改写端自动拼进上下文并标注"缓存，不必重读原文"

切层规则：context.py 原文窗口是 30 天，所以概括从 30 天前起切——30天~3月一段（近端脾气），
更早一段（底色），段数 ≤2~3。重新分析会覆盖同层（表按 conv_name+period_start 去重），
建议隔 1~2 月刷新近端那段。悬浮窗右键「重载上下文库」生效。

**闭环是双向的**：分析端出卡 → 改写端按卡说话 → 改写中发现的实况回写卡的「近期观察」→
下次分析先读它。两个 skill 靠 persona_cards/ 文件互为接口，谁也不能只出不进。
人物卡学的是"这个人"；"规则本身"的教训（示例不对/判型口径出错/库流程坑）走第三条回路
**zuiti-evolve** 的经验库，复盘时本 skill 的流程和尺子也会被它复盘。

## 红线

- 只读本机记忆库。persona_cards/ 与 dumps/context.db 同级敏感，**绝不**入库/外发/上演示。
- 分析对象是用户本人时明说"自我视角样本"。
- 娱乐归娱乐：卡上保留一句"MBTI 是参考级标签不是心理测评"，别把型编成事实；
  钦点的型不评判对错，照用。
- **头像识人是刻板印象校准，不是看相**：只拿来定初版分寸（客气/严肃/放松），不下断言、
  不评头论足（不说"头像显得土/显老"这类评价）；对方一句话就能推翻头像印象，
  被打脸就按衰减曲线降权——说话永远比头像说了算。
