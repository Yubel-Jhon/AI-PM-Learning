# 嘴替 · 三分钟展示简介

**它是什么**：一个钉在屏幕角落的小窗。你在钉钉打完想发的话，按 Alt+Z，它把火气换成体面，改完直接发回去。全程本地模型，话不出这台电脑。

**什么时候用**
- 被老板深夜 @，随手回怕露怯
- 想怼人的话已经打在输入框里，发出去就是事故
- 甩锅、试探、催进度、拒需求，分寸难拿捏

**能干什么**
- 一键改写，三档语气：高情商 / 强硬 / 损一点
- 本地跑，隐私安全
- 发不发你说了算：自动发出，或先预览再发

**三分钟怎么讲**
1. 开场（30 秒）：职场最贵的三个字是"已发送"，我做的东西专门拦这一下。
2. 演示（90 秒）：敲一句冲的话 → 按 Alt+Z → 出高情商版 → 换"强硬""损一点"各来一发 → 切预览模式按 Esc 撤销。
3. 收尾（30 秒）：三个不一样——本地、不替你越权、留了反悔的闸。
