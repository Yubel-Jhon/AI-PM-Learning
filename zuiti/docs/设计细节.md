## 人物分析方法论（它怎么知道该怎么跟 TA 说话）

改写不是裸改——**先弄清楚对面是谁，再决定怎么开口**。人物分析走「语料分层 → 三把尺子 → 应对翻译」，出卡的每句话都能倒推回数据：

```
聊天记录（分层）         三把尺子                    应对翻译
近 1 月：逐条细读   →   ① 说话解构（五维客观数据） →  说话节奏 / 信息颗粒
1~3 月：性格概括    →   ② MBTI 四轴判据（带证据）  →  入话顺序 / 收口方式
1 年以上：底色      →   ③ 语言地层学（年龄推断）   →  称呼与梗密度
                            ↓
                 人物卡（称号 / 标签 / MBTI / 代际 / 攻略难度 / 3do 3don't）
                     ↓ 回灌关系卡                  ↑ 观察回写
                 每次改写自动带这套分寸 ←—— 实况（新招式/判断被打脸）记回人物卡
```

**联动是双向的**：分析端把分寸交给改写端（人物卡盖过通用分寸表）；改写端在实战中发现
对方的新招式、或卡的判断被打脸时，回写进人物卡的「近期观察」段，下次分析先读它——
两个 skill 互为接口（persona_cards/ 文件），越用越准。

### 尺子① 说话解构——客观数据先行

| 维度 | 信号 | 读法 |
|---|---|---|
| 节奏 | 主动率、回复延迟中位数 | 谁迁就谁：总是 TA 先开口 = 关系里的发动机 |
| 体量 | 平均句长 | 惜字如金 vs 小作文选手 |
| 情绪 | emoji 率、语气词、问句率 | 表情包战士 / 问号控 / 语气生硬 |
| 生物钟 | 发言时段分布 | 深夜批奏折的甲方 vs 晨型人 |
| 代际 | 年代锚点词 | 见尺子③ |

**去向**：五维拼进 MBTI 四维——主动率→E/I · 句长与梗→S/N · emoji 语气→T/F · 时间死板→J/P。
数字全是数出来的，模型只负责解读——MBTI 不是玄学，是同一批数字拼出来的。

### 尺子② MBTI 四轴——每轴都要给原句证据

| 轴 | 看什么 |
|---|---|
| E/I | 主动发起、短句高频轰炸 vs 少而长 |
| S/N | 时间地点数量纠细节 vs 比喻、聊趋势 |
| T/F | 就事论事甩数据 vs "辛苦/别急"关心人 |
| J/P | "定下来/排期"时间说死 vs "到时候看" |

每轴输出 **倾向 + 置信度（强/中/弱）+ 原句依据**；样本 <30 条只出统计卡不判型。
四条一起数 → 型（例：主动率 100% + 句长 16 字 0 梗 + 0 emoji 0 语气词 + 时间说死 → ENTJ），
同样这四条喂给改写引擎就是「强硬 · 火气」那档；用户钦点的型优先，四维证据只写"为什么像"。

### 尺子③ 年龄推断——语言地层学 + 头像网名信号

网络流行语是"强年代锚点"：语言习惯在青春期定型，锚点词使用峰只有 1~2 年、世代辨识度极高。

| 地层 | 锚点词 |
|---|---|
| 70-80后 | 大虾、灌水、斑竹、美眉 |
| 85-95 | 呵呵（当年的真诚笑）、给力、神马、伤不起 |
| 90-00 | yyds、绝绝子、awsl、666 |
| 00-05后 | 尊嘟假嘟、city不city、那咋了、偷感、班味 |

规则：单词 ±5 岁、**词汇组合** ±3 岁；注意"形成期锚定"——中年人用年轻时的"呵呵"是真诚义不是嘲讽；微信 [微笑][玫瑰] 一族 bracket 表情是独立的中老年信号。

**头像网名信号（2026-09 升级，权重高于词表）**——头像和网名比聊天记录更诚实：
词会过时，频率和形象不会骗人；网名头像能换，说话习惯改不掉。

| 落位 | 网名 | 头像 |
|---|---|---|
| 往年长排 | 心境型：清风明月 · 海阔天空 · 平安是福 | 山水 · 荷花 · 日出 · 全家福 |
| 中间地带 | 身份型：张总 · 厦门-建材-王姐 · Leo·采购 | 默认字母图 · 汽车 · 背影照 · 商务壁纸 |
| 往年轻排 | 玩梗型：那咋了 · 尊嘟假嘟 · Ivy☆ | 动漫 · 游戏截图 · 情头 · 插画 |

词表与头像网名打架 → 以头像网名为准、词表做旁证。

### 初见陌生人——头像识人（零语料冷启动）

刚加上好友，一句聊天记录都没有，**头像就是第一句话**：贴头像+网名 → 三原型归类 →
初版分寸（初见默认客气三分和蔼一点；头像老成再严肃一点；头像年轻玩梗系再轻松一点）。
不出 MBTI、不评攻略难度。**初印象会过期**：刚加上头像网名说了算（≈95%）→
聊三五天各占一半 → 一周往后只按说话来（≈8%），语料够了就转正常分析流程。

### 应对翻译——把人物卡变成说话策略

| 判断 | 改写策略 |
|---|---|
| T（讲理） | 先结论后理由，直接上数据 |
| F（重情） | 先接住情绪再谈事 |
| J（计划） | 时间说死、给明确下一步 |
| P（灵活） | 留弹性、别逼死线 |
| S（具体） | 给时间/地点/数量，少谈概念 |
| 长辈代际 | 少用网络梗，称呼工整、句读干净 |

## 改写质量（v2）

- 提示词带**每档语气 3 条示例**（7B 模型对示例比对指令敏感），先判断对方那句话在干什么（甩锅/催/压/正常沟通）再落笔。
- 成稿有**质检**，两层：
  - **格式 lint**：客服腔（收到~/感谢您的理解与支持/请您放心…）、残留脏字、说明性文字泄漏、emoji 超量、超 50 字；
  （lint 会把成稿转小写再比脏字表，所以表里**别放大写变体**；拼音简写 tm/tmd/sb 必须收——
  草稿里"他妈"九成打成 tm，漏一个，模型挂掉时规则兜底就把脏字原样发出去了。）
- **原意保持度**：拒绝被改成答应、答应被改成拒绝、成稿出现原话没有的数字、时间口径漂移（周三→周五）——事实被改走本地规则兜底，绝不发出去。
- 任一层不过 → 自动带违规原因重试一次；仍不过但没改事实 → 容忍保留并说明；事实被改 → 宁可退回保守规则版。
- **规则兜底也会过硬规则**：兜底稿超 50 字会按标点截断，删脏字删到只剩残片（"傻B玩意"→"玩意"）则换成中性保守句，不发碎片。
- **两张脏字表要同步改**（`script/zuiti_overlay.py`）：模块级 `_CURSE_WORDS` 判草稿火气→推语气档；
  类属性 `ZuitiApp._CURSE` 判成稿残留 + 喂规则兜底。历史上两张表各改各的，导致兜底漏字——改一处记得改另一处。
- **自我卡（模仿你的语气）**：从 `context.db` 里你发过的消息提炼说话风格（句长/称呼/语气词/emoji 习惯）+ 5 条原话样本注入提示词，成稿模仿你本人的口吻。改写硬规则优先于风格。库缺你的消息或消息少于 8 条时自动不注入。
- 预览模式的"换个说法"**拿原始草稿重改**（之前是在上一版上继续改，意思会越漂越远），且预览窗**不再 30 秒不选就自动发出**——不选就一直等。
- **预览窗三件套（v3）**：①说明行——对象/语气档（自动推档会交代"检测到火气"）/对方疑似招式识别（本地规则推断，标"疑似"）；②流式改写——边出字边进框，质检不过当场清框重写，全程看得见；③可编辑成稿——Enter 发的是框里当前文字（先改再发），发送前自动把焦点还给 Alt+Z 时的窗口，不会粘错地方。

## 三个语气模式（悬浮窗上点，选中后下方显示大白话说明；也可改 `config.json` 的 `mode`）

- 高情商 `polish`：把你想说的话改得体面、有分寸，截图也不怕。
- 强硬 `firm`：立场更硬、先把边界钉死，但不失礼。
- 损一点 `drama`：更有梗更损，却还是发得出去的体面话。

> 想"替你回复对方发来的消息"，用聊天里的 `zuiti` 技能（说"嘴替 + 贴那条消息"），
> 悬浮窗只做"改写你正在输入框里打的话"这一件事。

## 上下文记忆库（可选，让改写"记得你俩聊过啥"）

悬浮窗自己调不动 dws（走 QwenWork 宿主认证），所以记忆库由 QwenWork 侧维护、脚本只读本地库：

- `context.db`（SQLite）：`conversations` / `messages`(近 1 月原文·强记忆) / `summaries`(更早摘要) / `relationship_cards`(永久关系卡)。
- 面板顶部「对象」下拉：选某个常用对话 → 改写时自动带上"关系卡 + 近期原文"作上下文；选「通用」→ 不带（退回无上下文）。
- 关系卡**不随时间衰减**，是"关键关系永久保留"的载体。
- 刷新方式：由 QwenWork 用 `dws chat +chat-messages --output …` 拉取，再在 script/ 里跑 `python build_context_db.py` 重建库（可挂定时任务）。
- 增删常用对话：改 `script/build_context_db.py` 里的 `CONVS` 清单。

> 当前 v1：强记忆=最近 1 个月原文 + 关系卡；更早的"摘要"层已建好表结构，尚未自动生成（需要时再接模型压缩）。

## 关于"发送前拦截"的实话

钉钉是封闭客户端，**没有**发送前 hook。本脚本用系统级模拟逼近该效果（抓选区→改写→粘回→回车），
不是真钻进钉钉内部。因此：

- 需要你的光标焦点在钉钉输入框；脚本运行瞬间别切窗口。
- 剪贴板会被临时占用，结束会还原，但期间别手动复制。
- **默认弹预览窗，不自动发**（`auto_enter: false`）：改写**边出字边显示**（流式），顶部说明行交代
  对象/语气档/对方疑似招式，质检过程当场直播；出完字**框里可直接改**，Enter 发的是改过的版本 /
  Esc 放弃 / Alt+R 拿原始草稿换一版。不想等预览，把悬浮条上「自动发出」切成"开"，就是
  `grace_seconds` 秒内按 Esc 可反悔的自动发出（一旦发出去就撤不回了，慎用）。
- 若你的钉钉是"Ctrl+Enter 发送"，把 `config.json` 的 `send_key` 改成 `ctrl+enter`。
- `grace_seconds` 是自动发出前的反悔缓冲秒数，期间按 Esc 可取消。

## 配置项（config.json 全量）

| 键 | 含义 |
|---|---|
| provider | 引擎：`api`（云上大模型，默认）/ `ollama`（本地隐私档） |
| api_base | OpenAI 兼容端点，默认 DashScope；GLM 等兼容端点换这里即可 |
| api_model | api 档模型名，默认 `qwen3.8-flash`（qwen3 系已自动关思考；嫌慢/不稳换 `qwen-plus`）|
| ollama_host | Ollama 地址（ollama 档用） |
| model | 本地模型名，需与 `ollama list` 一致（ollama 档用） |
| hotkey | 全局热键，`keyboard` 库格式，如 `alt+z` / `ctrl+alt+space` |
| mode | 默认模式 polish/firm/drama（reply 走聊天里的 zuiti 技能，悬浮窗不接） |
| auto_enter | true 自动发出（`grace_seconds` 内按 Esc 可反悔）；false 弹预览等你拍板，**默认 false** |
| send_key | 发送键 enter 或 ctrl+enter |
| grace_seconds | 自动发出前的反悔缓冲秒 |
| keep_alive | 模型常驻内存时长（默认 `30m`），启动时会后台预热，首次改写不用等冷启动 |
| num_ctx | 上下文窗口（默认 `4096`）。Ollama 默认 2048，带记忆库改写会被截断 |
| temperature | 默认 `0.5`，改写求稳；"换一版"会临时 +0.25 |
| mimic_me | 自我卡开关（默认开），右键菜单也能切。从库里你的历史消息提炼口吻，让成稿像你本人 |
| my_name | 你在钉钉里的名字。自动检测不可靠（发言最多的往往是别人），建议写死自己的名字 |

## 路径与自检（出了问题先跑这个）

| 东西 | 定义在哪 | 默认 |
|---|---|---|
| API key（api 档引擎） | `script/local_settings.json`（gitignore 排除）或环境变量 `DASHSCOPE_API_KEY` | 无 |
| 记忆库 context.db | `script/context.py` 的 `DB` | script/ 同目录；环境变量 `ZUITI_DB` 可覆盖 |
| dumps 钉钉导出 | `script/build_context_db.py` 的 `DUMPS` | script/dumps/ |
| 演示库 | `script/build_demo_db.py` | script/demo_context.db |
| 人物卡输出 | chat-persona skill 的 persona_export.py | 库同目录 persona_cards/ |

读库失败**不静默**：控制台打 `[context] xxx 失败: 原因`；悬浮窗就绪状态栏显示
"引擎 xxx · 记忆库 X会话/X条"（没建库会明说"只走通用模式"，没配 key 会明说"回退本地"）。
**双击 `script/检查环境.bat`** 一次看全：生效库/每会话条数/自我卡/dumps 缺口/config/Ollama 在线情况，
每个 ✗ 后面都带"修：xxx"。

## 停止

右键悬浮条 → 退出；或关闭命令行窗口。热键失效多半是 `keyboard` 需要权限，
用管理员身份重跑 `script/启动嘴替.bat`。
