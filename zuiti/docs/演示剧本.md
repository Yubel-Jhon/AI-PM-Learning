# 嘴替 · 现场演示剧本

> 原则：现场只演排练过的场景。模型有随机性，每条草稿上台前至少真跑 5 遍；
> 全程录屏备份，翻车就切录屏，嘴上说"这是刚才真实跑的一段"。

## 开演前检查（3 分钟）

1. 双击 `build_demo_db.py` 重跑一遍（或确认 `demo_context.db` 存在）
2. 双击 **`启动嘴替-演示.bat`**——注意必须是演示版启动，真库不上台
3. 悬浮窗拖到不挡输入框的位置；确认 Ollama 在跑（`ollama list`）
4. 打开一个空记事本当"输入框"练手，跑一遍热场草稿让模型进内存
5. 面板切**预览模式**（自动发出=关）——现场一个字都不要真的发出去

## 场景一 · 深夜改方案（对象：张总 / 高情商）

- 操作：对象下拉选「张总」→ 输入框敲 ↓ → Alt+Z

  > 改改改，一天改八遍，到底想怎样？？？

- 一边出稿一边讲：「它先认出对面是老板，翻了我俩最近的对话，知道方案是往哪改的——所以它不会改成"好的收到"，会落到"对齐方向"上。」
- 亮点：语境注入 + 对象分寸。预期出稿里有"标准/方向/对齐"一类的事务词，不带情绪。

## 场景二 · 甩锅现场（对象：王姐 / 强硬）

- 操作：对象选「王姐」→ 敲 ↓ → Alt+Z（自动语气应推到"强硬"）

  > 自己签收的东西来问我，你有没有脑子

- 讲：「草稿里有火气，它自动把语气档推到强硬——但注意，拒绝的立场不能被改软，这是我这产品的质检红线：**"不做"不能被改成"没问题"**。」
- 亮点：火气识别 + 原意保持度。可以追问演示：让它"换个说法"再来一版。

## 场景三 · 群里被催（对象：项目推进群）

- 操作：对象选「项目推进群」→ 敲 ↓ → Alt+Z

  > 催催催，没看见我这边还没跑通吗

- 讲：「群聊的口径要收敛，它知道群里不能点名怼人——上下文里有我之前在群里报过'后天出第一版'，所以成稿会往"已排期"上靠，不空口答应新时间。」
- 亮点：群分寸 + 不凭空承诺。

## 场景四 · 质检兜底（模型不可用也能演）

- 操作：对象选「通用」→ 敲 ↓ → Alt+Z

  > 这tm什么需求，谁提的谁来做

- 讲：正常版本讲 lint 禁词（"亲/收到~/感谢您的理解"全在黑名单里）。
- **彩蛋预案**：如果现场模型卡住，顺势演示降级——「就算本地模型挂了，它也不会让你把脏话发出去，规则兜底先把脏字洗掉」。故障变卖点。

## 场景五 · 反悔闸（收尾）

- 操作：预览模式下任一改写 → 预览窗里改写**边出字边显示**；顶部说明行念一遍
  （对象/语气档/对方疑似招式），质检行会直播「✓ 通过 / ⚠ 重写中」；想秀反悔闸就按 **Esc**
- 讲：「职场最贵的三个字是"已发送"。所以架构上"发出"是个显式动作——嘴长在它身上，门在我手里。
  而且发之前你还能在框里改字，Enter 发的就是你改过的版本。」
- 收尾一句：「全程本地，话不出这台电脑。」

## 翻车预案

| 现场 | 接法 |
|---|---|
| 改写慢（>8 秒） | 「改写是流式的，字在预览框里边出边看，不是黑箱干等」→ 顺带讲 keep_alive 预热机制 |
| 出稿一般 | 点「换个说法」——顺便演示 variation 机制，别干等 |
| 输出怪异 | 「这正是为什么要质检+预览闸：烂输出到不了发送那一步」→ Esc |
| Ollama 挂 | 场景四彩蛋路径，讲规则兜底 |

## 别忘了说

- 演示库是脱敏脚本人设（张总/王姐是演的），**真实库不带上台**——被问就答：「记忆库来自我自己钉钉的导出记录，隐私数据不进演示」
- **引擎**：现在默认走 api 档（云上大模型，效果最好）。要讲「全程本地，话不出这台电脑」的收尾金句，
  开演前把 `config.json` 的 `provider` 切成 `"ollama"`（一行）。或者反过来当亮点讲：
  「引擎可切——演示隐私档，日常用质量档；api 挂了自动回本地模型，本地也不行才走规则兜底」
- 三分钟版结构：已发送最贵（30s）→ 场景一/二（90s）→ 反悔闸+本地（30s），对应《三分钟展示简介.md》
