小替 · 系统架构 v3

一句话：钉钉没有发送前接口，就在系统层造一个「闸」——草稿抓取 → 认人定档 → 双引擎改写 → 两层质检 → 用户拍板。悬浮窗自动挡与 Claude skill 手动挡跑同一套规则； 记忆库 + 人物卡双库喂分寸，越用越准。

skill 双件套 · 同一套规则的两个壳

悬浮窗是「自动挡」：Alt+Z 嵌在输入流程里，规则写死在代码。skill 是「手动挡」：把原话丢给 Claude（"嘴替 + 贴那条消息"），走同一套改写规则——两壳一芯，规则改动两处同步。

手动挡 · skill（skill/）

  • zuiti-rewrite三档语气 / 硬规则 / 候选模式 A·B·C

认人三路：有人物卡 → 读卡（先读「近期观察」）；无卡刚加上好友 → 头像识人 （初印象衰减：刚加上 ≈95% → 三五天 ≈45% → 一周后 ≈8% 只按说话来）；都无 → 通用分寸表。 落点铁律：人物卡决定「怎么对他说话」，招式识别决定「这话在干什么」， 硬规则决定「什么不能说」——三者冲突时：硬规则 > 人物卡 > 招式。
03

Alt+Z 一次按键的完整生命线

从按下热键到消息发出共 9 步，任何一步失败都不产生「半截动作」：要么完整发出，要么草稿原样保留。

STEP 1热键入队keyboard → job_q，busy 锁防连击
STEP 2备份剪贴板原始剪贴板内容暂存，结束后还原
STEP 3抓草稿Ctrl+C 选区 → 失败则全选兜底；>200 字中止
STEP 4定语气手动锁定 or 情绪词×对象自动推荐 + 疑似招式识别
STEP 5查缓存同请求直接出结果，不重跑引擎
STEP 6改写+质检拼 Prompt → 双引擎 → 清洗 → 两层质检（详见 04）
STEP 7写缓存仅成功结果入缓存，上限 30 条
STEP 8发送闸预览窗拍板 / 自动发出 grace+Esc 反悔
STEP 9还原现场剪贴板还原，状态回报悬浮窗
STEP 5 分支：缓存命中 → 直接跳 STEP 8 STEP 8 分支：预览「换个说法」→ 拿原始草稿回 STEP 6（温度 +0.25，不在上一版上链式改）
04

两层质检闭环 · 模型的短板用工程补

示例管风格，质检管底线；风格要像人，底线是「截图不怕、原意不走样」。把「发现坏输出 → 带原因重教」做成模型外的工程闭环，而不是指望模型自己争气。

引擎出稿流式回调 · 边出字边进预览框
清洗器剥前缀/引号 · 卡 50 字
① 格式 lint6 类违禁模式
② 原意保持度立场 / 数字 / 时间
过关 → 交付写缓存 · 进发送闸
任一层不过收集违规原因
带原因重试 ×1「你上一版的问题：xxx」注入 system
二次质检同一把尺子
仍不过 → 兜底没改事实容忍保留并说明 / 事实被改退保守规则版
① lint 六类：客服腔（收到~/感谢您的理解与支持/请您放心…）· 脏字残留（含拼音简写 tm/tmd/sb）· 说明性文字泄漏 · emoji 超量 · 太短没信息量 · 超 50 字 ② 原意保持度三类：拒绝不能被改成答应、答应不能被改成拒绝 · 成稿不许出现原话没有的数字 · 时间口径不漂移（周三→周五 / 上午→下午）。丢弃细节不算违规，只查「改了」。 两张脏字表要同步改：模块级 _CURSE_WORDS 判草稿火气 → 推语气档； ZuitiApp._CURSE 判成稿残留 + 喂规则兜底——改一处记得改另一处。

06

降级矩阵 · 每种坏都有预案

架构图思维的关键一条：不画「一切正常」的图。每条依赖都问一句「它挂了用户看到什么」——答案必须是有感知、无事故。

故障 / 异常策略用户感知
云端 api 未配 key / 超时_call_llm 自动回本地 Ollama 再试一次；本地也不行才走规则兜底（删脏字、软化反问、收敛标点），绝不原样发出状态条提示「回退本地」→「已本地降级」
出稿含违禁 / 改了事实两层质检带原因重试 ×1 → 仍不过：没改事实容忍保留并说明；事实被改 → 退回保守规则版无感只在预览窗看到干净成稿
记忆库缺失 / 表空build_context 返回空串 → 退回无上下文通用改写，不静默、控制台打原因无感状态条明说「只走通用模式」
人物卡缺失退回通用分寸表；改写端顺手提醒「跑一次人物分析并落缓存，以后就自动了」无感分寸按通用档
抓取内容 >200 字判定误选（选到了聊天记录而非草稿）→ 直接中止，不动剪贴板明确报错「抓到内容过长，已中止」
草稿为空 / 未选中中止并报错，不进入改写明确报错「没读到你写的字」
预览无操作不动作（v1 旧版 30 秒自动发出已移除）一直等拍板权完全在人
config.json 损坏回退 DEFAULT_CONFIG 继续跑控制台提示面板行为回默认
07

四条设计原则

🔒隐私是可选档

默认云端质量档（key 只在 local_settings.json / 环境变量）；一行配置切 Ollama 隐私档，草稿、记忆、质检全程不出机。隐私按需选，不绑架效果。

🚧发送必须过闸

默认预览拍板；自动发出也留 1.2s grace + Esc 反悔。架构上「发出」是显式动作，不是改写的副作用。

🤝不侵入宿主

不钻钉钉内部、不 hook 进程，全部系统级模拟（剪贴板+按键）。代价是焦点与剪贴板的临时占用，用「还原现场」补偿。

🎯质检在模型外

示例管风格，质检管底线。不管引擎是云端还是本地，lint + 原意保持度都跑在模型外的工程闭环里——模型可以换，底线不换。

08

演进路线

v1 单轮改写已退役

  • 纯指令 Prompt，输出风格随缘
  • 换一版在上一版上链式改，意思漂移
  • num_ctx 缺省 2048，带记忆即截断
  • 无预热，首次按键冷启动干等

v2 质检闭环已收编

  • 每档 3 条 few-shot 示例 + 招式识别
  • lint → 带原因重试 → 规则兜底 三级防线
  • keep_alive 常驻 + 启动预热 + 结果缓存
  • 换一版回归原始草稿，温度 +0.25 出变体

v3 双引擎 + 双件套当前版本

  • 双引擎：云端千问默认 · Ollama 隐私档 · 自动回退
  • 两层质检：格式 lint + 原意保持度（立场/数字/时间）
  • 预览窗三件套：说明行 · 流式出字 · 可编辑成稿
  • 自我卡模仿口吻 · 人物卡+头像识人 · skill 双件套入库

v4 候选方向待定

  • 摘要层自动生成，强记忆跨月不丢
  • 对象自动识别（免手选下拉）
  • 悬浮窗三候选并行（手动挡已有候选模式 A/B/C）
